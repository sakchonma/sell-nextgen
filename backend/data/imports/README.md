# วางไฟล์ Excel ที่นี่

วางไฟล์ล่าสุดของ 2 ไฟล์นี้ (ชื่อไฟล์เปลี่ยนได้ ระบบดูจากชื่อชีท):

| ไฟล์ | ระบบจำจาก | เข้าเมนู |
| --- | --- | --- |
| Nextgen_Corporate_Sales_Launch*.xlsx | มีชีท `รายชื่อทั่วประเทศ` | Leads องค์กร |
| Nextgen_Faculty_Orientation_Research*.xlsx | มีชีท `เจาะรายคณะ` | Leads มหาวิทยาลัย |

แล้วรันจากโฟลเดอร์ `backend`:

```bash
npm run import:segments:excel -- --dry-run   # ดูก่อนว่าอ่านได้กี่รายการ
npm run import:segments:excel                # นำเข้า / อัปเดตเข้า MongoDB ตาม backend/.env
```

กติกาการอัปเดต (รันซ้ำได้เสมอ):

- แถวใหม่ (รหัส L/FAC ใหม่) → เพิ่ม lead ใหม่
- แถวเดิม → ข้อมูลวิจัยทุกคอลัมน์อัปเดตตามไฟล์
- สถานะในไฟล์เปลี่ยน → อัปเดตเฉพาะเมื่อขยับไปข้างหน้า หรือเป็น Won/Lost (ไม่ถอยงานที่ทีมทำในระบบ)
- วันนัดติดตามในไฟล์เปลี่ยน → ใช้วันใหม่ และอัปเดตงานในปฏิทิน
- ผู้ดูแล, โน้ต, ผู้ติดต่อที่ทีมแก้แล้ว → คงไว้ (ผู้ติดต่อใหม่จากไฟล์จะถูกเพิ่ม)
- แถวที่ถูกลบออกจากไฟล์ → ไม่ลบออกจากระบบ

ไฟล์ .xlsx ในโฟลเดอร์นี้ไม่ถูก commit ขึ้น git
